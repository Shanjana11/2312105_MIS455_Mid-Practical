# Glow Skincare

Glow Skincare is a simple 3-page e-commerce website for selling skincare products online. It was built with HTML, CSS and JavaScript as part of a midterm project of MIS455.

## Live Website

[glow-skin-care.netlify.app/](https://glow-skin-care.netlify.app/)

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Welcome banner, "Why Choose Us" cards, our story and a skincare tip button |
| Products | `products.html` | 12 skincare products in a grid, with a shopping cart that calculates prices |
| Contact Us | `contact.html` | Contact details and a message form with validation |

## Features

- Header, footer and navigation bar with hover effects on every page
- Home page layout built with CSS `display: flex`
- Products page layout built with CSS `display: grid`
- Shopping cart that shows each item, the total price, the discount and the final payable amount
- Tk 500 discount on purchases of Tk 3000 or more
- Buttons using the `onclick` event handler: Get a Skincare Tip, Add to Cart, Show Cart, Clear Cart and Send Message
- Contact form that checks that all fields are filled in
- Responsive design that works on phones, tablets and desktops
